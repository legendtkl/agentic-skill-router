Quick Start

常用安装和初始化路径直接放在页面里；完整参数仍以 README 和 CLI help 为准。

全局安装 
npm install -g agentic-skill-router
agentic-skill-router init

推荐先全局安装，让生成的 skill 能引用稳定的 CLI 路径。

Codex 项目级入口 
agentic-skill-router init codex project
agentic-skill-router skills list

在当前项目写入 Codex 可发现的路由 skill，不影响其他项目。

Claude Code 项目级入口 
agentic-skill-router init claude-code project
agentic-skill-router skills suggest

初始化时会维护带 fence 的 CLAUDE.md routing block，重复运行保持幂等。

本地 Web 管理页 
agentic-skill-router skills web
# http://127.0.0.1:8787

用于浏览、筛选、禁用和恢复本机技能；默认只绑定 loopback。

路由禁用技能 
agentic-skill-router skills route \
  --query "draft a Lark mail reply" \
  --json

从禁用技能语料中选择匹配项，输出可被 agent workflow 消费的结构化结果。

恢复技能 
agentic-skill-router skills status
agentic-skill-router skills enable user:codex:lark-mail

通过状态记录恢复 SKILL.md；内置和系统技能保持受保护。

核心功能

项目围绕一个目标设计：降低常驻 skill 元数据成本，同时保持禁用、恢复和按需路由都可控。

技能盘点

枚举 Codex、Claude Code、项目目录、用户目录和插件目录中的技能，并识别内置系统技能。

基于使用记录瘦身

读取本地 transcript，统计技能调用痕迹，按最近使用时间给出 stale 或 unused 建议。

安全禁用与恢复

通过重命名 SKILL.md 禁用技能，保留状态文件，保护内置和系统技能不被误改。

禁用技能路由

当已启用技能无法覆盖请求时，从禁用技能语料中检索并选择更合适的技能。

本地 Web 管理页

内置 localhost Web UI，可浏览、筛选、禁用和恢复技能；公网绑定需要显式危险开关。

CLI 与插件分发

提供 npm CLI、Codex slash prompt、Claude Code 插件资产和统一的技能工作流定义。

运行机制

agentic-skill-router 不复制宿主的内置技能系统，而是在技能目录和宿主触发机制之间增加一层可审计的路由。

1 初始化 init 安装项目或全局技能入口，并写入对应宿主需要的触发资产。
2 扫描 汇总技能元数据、来源、冲突和禁用状态，形成当前可操作清单。
3 瘦身 suggest 结合使用记录生成候选项，再由用户确认禁用。
4 路由 请求需要禁用技能时，路由工作流在语料中选择目标 skill 并读取其指令。
5 恢复 enable 使用状态记录还原 SKILL.md，也能处理缺失状态的修复路径。

批量实验结果

最新聚合数据来自 experiments/dci-compare/runs/rerun-150-full-2026-05-26： 48 个聚合行，1,152 个实验单元，覆盖 Claude、Codex、16 个路由变体与 24 个专家查询。

Codex 结果

I-meta 与 E-digest 达到 24/24； I-meta 成本为 $3.02，是最新 Codex 组的高准确率低成本点。

Claude 结果

B-cc 最高为 23/24；更受控的 K-lite 以 22/24 和 $4.06 提供更低成本的折中点。
