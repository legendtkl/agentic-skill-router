3. 1K synthetic × Codex codex

L-agentic (CLI-driven corpus search/inspect + structured candidates) is the only variant scaled past 150. The 1K corpus = 150-skill comparison set + 850 synthetic noise skills drawn from the easy pool. This validates that the L abstraction's index + pagination handles ~7× the candidate pool without prompt blowup.

1K miss: pptx-reference-formatting → skill-103. Avg ctxend only grows from 17.5K → 17.9K, confirming CLI pagination prevents prompt blowup.

4. 79K Hard × Claude Code claude

J-bounded-v2 scaling from 150 to 79,141 Hard pool (SkillRouter eval-core/hard). v2 fixes v1's shell glob ARG_MAX overflow (~13K paths cap) and removes head-20 truncation. Same 24 SkillsBench queries; bounded payload, cost only +35%, accuracy drops from 22/24 to 12/24.

Headline: J-bounded-v2 is mechanically stable at 79K (bounded ctx, no timeouts) but accuracy collapses from 91.7% → 50.0% because description-only signal is insufficient against the Hard pool's 780 LLM-distilled distractors. Metadata-only cannot serve as the sole decision source at this scale — body-on-tie / full-text rerank is required.
