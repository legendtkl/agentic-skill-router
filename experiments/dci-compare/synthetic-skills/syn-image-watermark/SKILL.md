# image files: applying watermarks

## When to use

Use this skill for applying watermarks in image files. This skill
specifically handles applying watermarks and nothing else in the
image files family.

## Procedure

Overlay a text or logo watermark with configurable opacity, position, and scaling.

## Notes

This is the image files skill dedicated to applying watermarks.
Sibling skills cover other image files capabilities; this one
is the right choice only when the task is about applying watermarks.
