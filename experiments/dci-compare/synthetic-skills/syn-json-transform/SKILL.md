# JSON data: reshaping and transforming structure

## When to use

Use this skill for reshaping and transforming structure in JSON data. This skill
specifically handles reshaping and transforming structure and nothing else in the
JSON data family.

## Procedure

Restructure JSON: rename keys, flatten/nest, and map between two shapes.

## Notes

This is the JSON data skill dedicated to reshaping and transforming structure.
Sibling skills cover other JSON data capabilities; this one
is the right choice only when the task is about reshaping and transforming structure.
