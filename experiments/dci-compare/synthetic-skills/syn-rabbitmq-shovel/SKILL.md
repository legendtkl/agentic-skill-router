# RabbitMQ: shovel and federation between brokers

## When to use

Use this skill for shovel and federation between brokers in RabbitMQ. This skill
specifically handles shovel and federation between brokers and nothing else in the
RabbitMQ family.

## Procedure

Set up the shovel/federation plugins to move messages between brokers or data centers reliably.

## Notes

This is the RabbitMQ skill dedicated to shovel and federation between brokers.
Sibling skills cover other RabbitMQ capabilities; this one
is the right choice only when the task is about shovel and federation between brokers.
