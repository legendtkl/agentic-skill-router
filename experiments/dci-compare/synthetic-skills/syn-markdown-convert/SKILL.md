# Markdown documents: converting to HTML or PDF

## When to use

Use this skill for converting to HTML or PDF in Markdown documents. This skill
specifically handles converting to HTML or PDF and nothing else in the
Markdown documents family.

## Procedure

Render Markdown to styled HTML or PDF with a template and syntax highlighting.

## Notes

This is the Markdown documents skill dedicated to converting to HTML or PDF.
Sibling skills cover other Markdown documents capabilities; this one
is the right choice only when the task is about converting to HTML or PDF.
