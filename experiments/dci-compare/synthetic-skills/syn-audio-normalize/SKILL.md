# audio files: loudness normalization

## When to use

Use this skill for loudness normalization in audio files. This skill
specifically handles loudness normalization and nothing else in the
audio files family.

## Procedure

Normalize loudness to a target LUFS, apply limiting, and even out volume across tracks.

## Notes

This is the audio files skill dedicated to loudness normalization.
Sibling skills cover other audio files capabilities; this one
is the right choice only when the task is about loudness normalization.
