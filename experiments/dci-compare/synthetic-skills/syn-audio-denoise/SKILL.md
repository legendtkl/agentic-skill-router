# audio files: noise reduction

## When to use

Use this skill for noise reduction in audio files. This skill
specifically handles noise reduction and nothing else in the
audio files family.

## Procedure

Remove background hiss/hum with noise profiles and spectral denoising.

## Notes

This is the audio files skill dedicated to noise reduction.
Sibling skills cover other audio files capabilities; this one
is the right choice only when the task is about noise reduction.
