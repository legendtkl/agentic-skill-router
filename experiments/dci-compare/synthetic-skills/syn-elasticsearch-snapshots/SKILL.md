# Elasticsearch: snapshot and restore

## When to use

Use this skill for snapshot and restore in Elasticsearch. This skill
specifically handles snapshot and restore and nothing else in the
Elasticsearch family.

## Procedure

Register a snapshot repository, schedule snapshots with SLM, and restore selected indices after data loss.

## Notes

This is the Elasticsearch skill dedicated to snapshot and restore.
Sibling skills cover other Elasticsearch capabilities; this one
is the right choice only when the task is about snapshot and restore.
