# RabbitMQ: dead-letter queues and retries

## When to use

Use this skill for dead-letter queues and retries in RabbitMQ. This skill
specifically handles dead-letter queues and retries and nothing else in the
RabbitMQ family.

## Procedure

Configure dead-letter exchanges, TTL-based retry queues, and a parking-lot queue for poison messages.

## Notes

This is the RabbitMQ skill dedicated to dead-letter queues and retries.
Sibling skills cover other RabbitMQ capabilities; this one
is the right choice only when the task is about dead-letter queues and retries.
