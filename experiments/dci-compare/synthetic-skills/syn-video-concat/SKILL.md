# video files: concatenating multiple videos

## When to use

Use this skill for concatenating multiple videos in video files. This skill
specifically handles concatenating multiple videos and nothing else in the
video files family.

## Procedure

Concatenate several clips into one file, handling mismatched codecs and resolutions.

## Notes

This is the video files skill dedicated to concatenating multiple videos.
