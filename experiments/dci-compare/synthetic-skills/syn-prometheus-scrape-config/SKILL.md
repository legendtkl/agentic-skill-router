# Prometheus: scrape and service-discovery configuration

## When to use

Use this skill for scrape and service-discovery configuration in Prometheus. This skill
specifically handles scrape and service-discovery configuration and nothing else in the
Prometheus family.

## Procedure

Write `scrape_configs`, use service discovery, relabel targets, and set scrape intervals/timeouts.

## Notes

This is the Prometheus skill dedicated to scrape and service-discovery configuration.
Sibling skills cover other Prometheus capabilities; this one
is the right choice only when the task is about scrape and service-discovery configuration.
