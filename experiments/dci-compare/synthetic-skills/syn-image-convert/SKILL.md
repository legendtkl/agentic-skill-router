# image files: converting image formats

## When to use

Use this skill for converting image formats in image files. This skill
specifically handles converting image formats and nothing else in the
image files family.

## Procedure

Convert between PNG/JPEG/WebP/AVIF, manage quality, and strip or preserve metadata.

## Notes

This is the image files skill dedicated to converting image formats.
Sibling skills cover other image files capabilities; this one
is the right choice only when the task is about converting image formats.
