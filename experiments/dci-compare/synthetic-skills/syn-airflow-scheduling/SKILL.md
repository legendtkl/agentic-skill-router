# Apache Airflow: schedule intervals and catchup

## When to use

Use this skill for schedule intervals and catchup in Apache Airflow. This skill
specifically handles schedule intervals and catchup and nothing else in the
Apache Airflow family.

## Procedure

Configure schedule intervals/cron, `start_date`, timezone handling, and the `catchup` flag for historical runs.

## Notes

This is the Apache Airflow skill dedicated to schedule intervals and catchup.
Sibling skills cover other Apache Airflow capabilities; this one
is the right choice only when the task is about schedule intervals and catchup.
