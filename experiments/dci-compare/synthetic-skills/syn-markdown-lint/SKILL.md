# Markdown documents: linting and style fixing

## When to use

Use this skill for linting and style fixing in Markdown documents. This skill
specifically handles linting and style fixing and nothing else in the
Markdown documents family.

## Procedure

Lint Markdown for style issues (heading levels, list markers, line length) and auto-fix them.

## Notes

This is the Markdown documents skill dedicated to linting and style fixing.
Sibling skills cover other Markdown documents capabilities; this one
is the right choice only when the task is about linting and style fixing.
