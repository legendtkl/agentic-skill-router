# CSV data: schema validation

## When to use

Use this skill for schema validation in CSV data. This skill
specifically handles schema validation and nothing else in the
CSV data family.

## Procedure

Validate a CSV against a schema: required columns, types, ranges, and enum values; report violations.

## Notes

This is the CSV data skill dedicated to schema validation.
Sibling skills cover other CSV data capabilities; this one
is the right choice only when the task is about schema validation.
