# Apache Airflow: backfilling and reprocessing history

## When to use

Use this skill for backfilling and reprocessing history in Apache Airflow. This skill
specifically handles backfilling and reprocessing history and nothing else in the
Apache Airflow family.

## Procedure

Run targeted backfills for a date range, clear and re-run failed task instances, and reprocess after a logic fix.

## Notes

This is the Apache Airflow skill dedicated to backfilling and reprocessing history.
Sibling skills cover other Apache Airflow capabilities; this one
is the right choice only when the task is about backfilling and reprocessing history.
