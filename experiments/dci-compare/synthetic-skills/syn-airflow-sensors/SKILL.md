# Apache Airflow: sensors and external triggers

## When to use

Use this skill for sensors and external triggers in Apache Airflow. This skill
specifically handles sensors and external triggers and nothing else in the
Apache Airflow family.

## Procedure

Use sensors (file/S3/external-task) in reschedule mode, set timeouts/pokes, and trigger DAGs from external events.

## Notes

This is the Apache Airflow skill dedicated to sensors and external triggers.
Sibling skills cover other Apache Airflow capabilities; this one
is the right choice only when the task is about sensors and external triggers.
