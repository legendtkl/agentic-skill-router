# image files: resizing and rescaling images

## When to use

Use this skill for resizing and rescaling images in image files. This skill
specifically handles resizing and rescaling images and nothing else in the
image files family.

## Procedure

Resize images to target dimensions, preserve aspect ratio, and generate responsive size variants.

## Notes

This is the image files skill dedicated to resizing and rescaling images.
Sibling skills cover other image files capabilities; this one
is the right choice only when the task is about resizing and rescaling images.
