# audio files: applying fades and trimming silence

## When to use

Use this skill for applying fades and trimming silence in audio files. This skill
specifically handles applying fades and trimming silence and nothing else in the
audio files family.

## Procedure

Add fade-in/out, trim leading/trailing silence, and apply crossfades between clips.

## Notes

This is the audio files skill dedicated to applying fades and trimming silence.
Sibling skills cover other audio files capabilities; this one
is the right choice only when the task is about applying fades and trimming silence.
