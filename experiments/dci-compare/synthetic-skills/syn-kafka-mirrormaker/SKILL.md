# Apache Kafka: cross-cluster replication with MirrorMaker

## When to use

Use this skill for cross-cluster replication with MirrorMaker in Apache Kafka. This skill
specifically handles cross-cluster replication with MirrorMaker and nothing else in the
Apache Kafka family.

## Procedure

Configure MirrorMaker 2 connectors to replicate topics and consumer offsets between a source and a target cluster across regions.
