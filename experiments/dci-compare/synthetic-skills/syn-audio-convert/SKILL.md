# audio files: converting audio formats

## When to use

Use this skill for converting audio formats in audio files. This skill
specifically handles converting audio formats and nothing else in the
audio files family.

## Procedure

Convert between WAV/MP3/FLAC/AAC, set bitrate/sample rate, and manage tags.

## Notes

This is the audio files skill dedicated to converting audio formats.
Sibling skills cover other audio files capabilities; this one
is the right choice only when the task is about converting audio formats.
