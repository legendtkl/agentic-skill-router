# Prometheus: federation across Prometheus servers

## When to use

Use this skill for federation across Prometheus servers in Prometheus. This skill
specifically handles federation across Prometheus servers and nothing else in the
Prometheus family.

## Procedure

Configure `/federate` so a global Prometheus aggregates selected series from regional Prometheis.

## Notes

This is the Prometheus skill dedicated to federation across Prometheus servers.
Sibling skills cover other Prometheus capabilities; this one
is the right choice only when the task is about federation across Prometheus servers.
