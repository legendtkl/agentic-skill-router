# Markdown documents: generating a table of contents

## When to use

Use this skill for generating a table of contents in Markdown documents. This skill
specifically handles generating a table of contents and nothing else in the
Markdown documents family.

## Procedure

Scan headings and insert/update a linked table of contents in a Markdown file.

## Notes

This is the Markdown documents skill dedicated to generating a table of contents.
Sibling skills cover other Markdown documents capabilities; this one
is the right choice only when the task is about generating a table of contents.
