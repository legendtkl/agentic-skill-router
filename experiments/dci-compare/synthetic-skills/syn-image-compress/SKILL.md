# image files: compressing and optimizing file size

## When to use

Use this skill for compressing and optimizing file size in image files. This skill
specifically handles compressing and optimizing file size and nothing else in the
image files family.

## Procedure

Reduce image file size with lossy/lossless optimization while keeping acceptable visual quality.

## Notes

This is the image files skill dedicated to compressing and optimizing file size.
Sibling skills cover other image files capabilities; this one
is the right choice only when the task is about compressing and optimizing file size.
