# Apache Kafka: authorization ACLs and client quotas

## When to use

Use this skill for authorization ACLs and client quotas in Apache Kafka. This skill
specifically handles authorization ACLs and client quotas and nothing else in the
Apache Kafka family.

## Procedure

Define ACLs granting produce/consume on resources to principals, enforce per-client quotas, and audit access with the authorizer.
