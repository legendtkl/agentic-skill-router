# image files: cropping and aspect-ratio framing

## When to use

Use this skill for cropping and aspect-ratio framing in image files. This skill
specifically handles cropping and aspect-ratio framing and nothing else in the
image files family.

## Procedure

Crop images to a region or aspect ratio, with smart/centered cropping options.

## Notes

This is the image files skill dedicated to cropping and aspect-ratio framing.
Sibling skills cover other image files capabilities; this one
is the right choice only when the task is about cropping and aspect-ratio framing.
