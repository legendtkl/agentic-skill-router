# Elasticsearch: index lifecycle management

## When to use

Use this skill for index lifecycle management in Elasticsearch. This skill
specifically handles index lifecycle management and nothing else in the
Elasticsearch family.

## Procedure

Configure ILM policies with hot/warm/cold/delete phases, rollover on size/age, and attach policies to index templates.

## Notes

This is the Elasticsearch skill dedicated to index lifecycle management.
Sibling skills cover other Elasticsearch capabilities; this one
is the right choice only when the task is about index lifecycle management.
