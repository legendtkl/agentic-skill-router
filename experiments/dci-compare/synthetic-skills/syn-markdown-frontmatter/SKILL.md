# Markdown documents: editing YAML frontmatter

## When to use

Use this skill for editing YAML frontmatter in Markdown documents. This skill
specifically handles editing YAML frontmatter and nothing else in the
Markdown documents family.

## Procedure

Read, validate, and bulk-edit YAML frontmatter fields across many Markdown files.

## Notes

This is the Markdown documents skill dedicated to editing YAML frontmatter.
Sibling skills cover other Markdown documents capabilities; this one
is the right choice only when the task is about editing YAML frontmatter.
