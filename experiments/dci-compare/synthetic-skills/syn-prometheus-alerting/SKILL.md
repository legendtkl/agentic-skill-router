# Prometheus: alerting rules and Alertmanager routing

## When to use

Use this skill for alerting rules and Alertmanager routing in Prometheus. This skill
specifically handles alerting rules and Alertmanager routing and nothing else in the
Prometheus family.

## Procedure

Write alerting rules with `for` durations, severity labels, and route/group/silence them in Alertmanager.

## Notes

This is the Prometheus skill dedicated to alerting rules and Alertmanager routing.
Sibling skills cover other Prometheus capabilities; this one
is the right choice only when the task is about alerting rules and Alertmanager routing.
